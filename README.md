# RayveLabs

Source for **rayvelabs.com** — a small open research practice in cybersecurity, generative AI, network discovery, cryptography, public-sector technology, and practical security work.

## Site structure

| File | Purpose |
|------|---------|
| `index.html` | RayveLabs landing page — projects + contact |
| `rayvenet.html` | RayveNet — interactive network-discovery walkthrough |

## Hosting

Auto-deployed to Cloudflare Pages on every push to `main`.
Custom domain: **rayvelabs.com**.

## Editing

1. Clone or edit in place
2. Commit your change
3. `git push` — Cloudflare deploys within ~30 seconds

For future lab modules (Simulation 2, Simulation 3, etc.), copy `rayvenet.html` to a new filename and link it from the landing page's Projects section.
